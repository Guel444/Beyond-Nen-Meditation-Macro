# Changelog

## [1.0.0] - Initial public release

- Added automatic target detection for the Beyond Nen meditation minigame.
- Added hue-independent closing-ring measurement using the target's stable white outline as the visual anchor.
- Added predictive contact timing based on recent ring measurements.
- Added cursor pre-positioning and synchronized absolute mouse movement + left-button input through Windows `SendInput`.
- Added visual diagnostics, configurable capture region, timing adjustment, global hotkeys, and CSV logging.
- Added Windows batch launchers for standard and elevated execution.
